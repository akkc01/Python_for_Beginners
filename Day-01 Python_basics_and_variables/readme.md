
# 🐍 Python

Python is a **general-purpose, object-oriented, high-level, and interpreted programming language**.

It was created by **Guido van Rossum** and was first released in **1991**. Python is one of the most widely used programming languages because of its simple syntax, readability, versatility, and extensive ecosystem.

---

## 📌 What is Python?

Python is a high-level programming language designed to make code easy to read and write. It supports multiple programming paradigms, including:

* **Object-Oriented Programming (OOP)**
* **Procedural Programming**
* **Functional Programming**

Python is commonly used for:

* 🌐 Web Development
* 💻 Software Development
* 📊 Data Analysis
* 🤖 Artificial Intelligence & Machine Learning
* 🔢 Mathematics & Scientific Computing
* ⚙️ System Scripting & Automation
* ☁️ Cloud & DevOps Automation
* 🧪 Testing and Tool Development

---

## 🚀 Why Python?

### 1. Cross-Platform

Python works on multiple platforms, including:

* Windows
* macOS
* Linux
* Raspberry Pi
* Unix-based systems

The same Python code can generally run across different operating systems with minimal or no changes.

### 2. Simple and Readable Syntax

Python syntax is clean and easy to understand. It is designed to be close to natural language, making it beginner-friendly.

```python
name = "Amit"

print(f"Hello, {name}!")
```

### 3. Less Code

Python often requires fewer lines of code compared with many other programming languages.

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    print(number)
```

### 4. Interpreted Language

Python code is executed by the Python interpreter. This makes development, testing, and prototyping fast and convenient.

### 5. Multi-Paradigm Language

Python supports different programming approaches:

```text
Procedural
    ↓
Object-Oriented
    ↓
Functional
```

Developers can choose the approach that best fits their application.

### 6. Large Ecosystem

Python has a huge collection of libraries and frameworks for almost every type of development.

Popular examples include:

| Area             | Libraries / Frameworks            |
| ---------------- | --------------------------------- |
| Web Development  | Django, Flask, FastAPI            |
| Data Science     | NumPy, Pandas                     |
| Machine Learning | Scikit-learn, TensorFlow, PyTorch |
| Automation       | Selenium, Requests                |
| DevOps           | Boto3, Azure SDK, Ansible         |
| Testing          | PyTest, Unittest                  |

## 🛠️ Installing Python

Check whether Python is already installed:

```bash
python3 --version
```

Example:

```text
Python 3.13.5
```

You can then run Python using:

```bash
python3
```

## ▶️ Your First Python Program

Create a file named:

```text
hello.py
```

Add:

```python
print("Hello, World!")
```

Run it:

```bash
python3 hello.py
```

Output:

```text
Hello, World!
```
